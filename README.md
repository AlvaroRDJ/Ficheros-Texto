# Tarea 1 RA1 - Persistencia en ficheros de texto y binarios

Acceso a Datos (DAM). Cuatro ejercicios en Java sobre la clase File, FileWriter/FileReader y BufferedWriter/BufferedReader.

Rutas adaptadas a macOS: en lugar de C:\AD\Ejercicios se usa ~/AD/Ejercicios (obtenida con System.getProperty("user.home")).

## Ejercicios

- src/Ejercicio1.java: crea miDirectorio y fichero_de_texto.txt
- src/Ejercicio2.java: menu de 5 opciones (crear/eliminar directorios y ficheros)
- src/Ejercicio3.java: menu completo, borrado recursivo y escritura de provincias de Andalucia
- src/Ejercicio4.java: escritura y lectura de Empleados.txt con FileWriter/FileReader y Buffered

## Ejecucion

Abrir el proyecto en IntelliJ IDEA, clic derecho sobre el ejercicio deseado y elegir Run.
